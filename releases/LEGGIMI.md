# Previous versions of Voxelia

Here are the complete builds of the published versions: each one is a single `voxelia_v<version>.html` file with the
whole game as it was then. What changes in each version is in [CHANGELOG.md](../CHANGELOG.md) (in Italian, with every
version, in [CHANGELOG.it.md](../CHANGELOG.it.md)).

## How to play them

- **From the website**: in the game menu, "Previous versions". The server opens them only for solo play, with separate saves.
- From disk: open the file in the browser and play **alone**.
- The multiplayer of an old version only works with the server of that same version, which isn't here: today's server
  talks to today's game.
- **Watch out for saves when opening files from disk.** The browser keeps saves by address, not by version: an old
  version opened from the same place as the current version (for example from the same folder on disk) sees and can
  overwrite the same game, settings and Voxelia Studio worlds. Before trying it, export the worlds you need, or open the
  old version in a private window or another browser profile.
